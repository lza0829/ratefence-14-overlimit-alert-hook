# 限流篱

中文名：**限流篱** · 前缀 `ratefence` · 端口 **6900 / 11900**

## 骨架

**路由匹配 → 配额桶扣减 → 超限拒绝或排队 → 降级应答落账**

皮：API 限流控制台。去皮是 **路由配额 + 扣减 + 超限处置**，不是灰度下发、不是发版闸、不是业务 CRUD。

领域：**基础设施** · 子方向：**SRE & Ops**

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6900
# 配额桶 → 配额样例 → 路由册 → 路由样例 → 试流台连打 → 拒绝账
```
